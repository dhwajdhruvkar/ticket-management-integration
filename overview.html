Where we started — two different systems

Each was strong on one side and weak on the other. That is exactly why merging them works.

System 1 · Your build

The Helpdesk prototype

An AI-first ticket auto-resolution bot, running entirely in the browser.

Strengths kept

  • AI resolves repeat tickets before an agent sees them (RAG: retrieve → grounded answer)
  • Confidence scoring → auto-resolve / suggest / escalate
  • Tamper-evident SHA-256 audit chain
  • Semantic knowledge-base search; clean Zendesk-style UI

Limitations fixed

  • Data lived only in the browser (localStorage) — no real backend
  • No real login, roles, or multi-user support
  • Only incidents/requests — no Problem, Change, Asset/CMDB
  • No automation, omnichannel, or reporting
System 2 · Netlink original

The traditional ITSM

A classic, human-driven ITIL service desk (per the Netlink design docs).

Strengths adopted

  • Full ITIL modules: Incident, Request, Problem, Change, Asset/CMDB, Knowledge
  • Real backend (Postgres) + microservice-style structure
  • Authentication, roles & permissions (JWT / SSO / RBAC)
  • SLA tracking, assignment, approval workflows

Limitations improved

  • Every ticket resolved by a human — AI was only a "future phase"
  • Audit was a plain database table (editable, not tamper-evident)
  • Decisions weren't explainable or captured
  • Knowledge base was passive (an FAQ, not a resolver)

What we merged — the best of both ends

We took the AI + audit core from your Helpdesk, the ITIL backbone from Netlink's ITSM, and added the production glue that makes them one system.

From your Helpdesk →

  • RAG auto-resolution engine
  • Confidence-based routing & guardrails
  • Tamper-proof audit chain (now server-side, per tenant)
  • Semantic KB search & grounded, cited answers

From Netlink ITSM →

  • Incident · Service Request · Problem · Change · Asset/CMDB
  • Postgres backend + data model
  • Entra ID SSO + role-based access control
  • SLAs, assignment & CAB approval workflows

New in the merge ★

  • AI woven into every module (classify, risk-score, cluster, summarize)
  • Automation/rules engine + background jobs
  • Omnichannel intake (email, Teams, portal, webhooks)
  • Analytics & ROI dashboards + self-service portal
