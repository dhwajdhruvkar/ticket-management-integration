# API reference (discovered)

Every endpoint found under `src/app/api`, with the guard each handler applies. **Existing.** The table below is generated by a script over every `route.ts` (79 files, 118 handlers) and then checked by hand against samples; the "Guard" column is recognised by pattern (`requirePermission(req, "x")`, inline `can(role, "x")`, `isAgentRole()`, webhook signature checks). Where a handler's check is more nuanced than the pattern, the column says so and the route file is the authority.

For the integrator-facing contract, `docs/EXTERNAL_API_GUIDE.md` and the hand-written OpenAPI 3.1 document served at `GET /api/v1/openapi.json` (`src/app/api/v1/openapi.json/route.ts`, `src/server/workflowOpenApi.ts`) are the published descriptions. This file documents what the **code** exposes; the two disagree in five places (below).

|---|---|---|

## Notes on specific contracts

- **Ticket creation** (`POST /api/v1/tickets`): `subject` (≤300) and `body` (≤50,000) required; requesters file as themselves; callers may send `priorityMode: "manual"` only if staff, with `impact`, `urgency` and `priorityOverrideReason`; `requesterId`, idempotency hashes, `integrationKeyId` and `customFields` are discarded if sent. A requester-scoped API key (`ticket_submitter`) can create but not upload attachments.
- **Unified intake** (`POST /api/v1/intake`): one endpoint for `channel` values including `alert` (monitoring severity maps to impact and urgency and links a named CI), plus a `teams` activity form handled by `handleTeamsActivity`.
- **Workflow** (`POST /api/v1/tickets/:id/workflow`): body validated by `WorkflowActionSchema`; actions `claim_review`, `route`, `offer`, `pickup`, `accept`, `decline`, `release`, `return_to_service_desk`; stale writes return the message "Ticket changed. Refresh and try again."
- **Reports** (`GET /api/v1/reports`): JSON by default, `?format=csv` or `?format=pdf` (pdfkit; `next.config.mjs` traces pdfkit font data for this route).
- **Audit** (`GET /api/v1/audit`): `?verify=1` recomputes the hash chain and returns the verdict.
- **Cron** (`POST /api/jobs/workflow`): `Authorization: Bearer <CRON_SECRET>`, secret ≥32 chars, compared with `timingSafeEqual`; `maxDuration` 60 s; returns sweep counters or 503.
- **Health** (`GET /api/v1/health`): public; reports driver, auth mode, attachment storage and feature flags, and a hard-coded `version: "2.0.0"` that differs from `package.json` `1.0.0`.

## Unknowns

- Response body shapes for each endpoint beyond the envelope: they are the service return types (`TicketRow`, `TicketView`, …) and were not enumerated here. The OpenAPI document describes many of them.
- Whether any consumer other than the bundled UI and the documented integration calls these endpoints.
